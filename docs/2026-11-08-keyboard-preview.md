## 协议说明与限制

- 角度仍按度乘 10000 编码，手动转向沿用 `found=2`；导航字段为零。
- 发射字段参考 `Armor/sentry/adapter.cpp` 的装甲板链路，采用 `fire=1/0`，位于 21 字节数据包的索引 19。未混用能量机关的 `fire=2`。
- 本仓库没有电控接收代码，尚未确认电控是否支持 `found=2, fire=1` 的组合。发送请求不代表已经实际发射。
- 空格为人工发射请求，不调用自动瞄准 `Shooter` 的跟踪、对齐等判定。目标像素中心只是候选方向，不是经过弹道验证的命中点。
- 默认速度 5 度/秒，可配置轴向；相对启动反馈角度限制为正负 10 度，移动指令领先当前反馈不超过 1 度。这些软件限制不能替代实际机械限位。
- 松手后的行为是发送当前反馈角度保持指令，实际制动、断连后的停止和发射机构响应仍依赖电控。Qt 事件循环不是实时控制器，检测耗时可能影响输入处理延迟。

## 构建与使用

除原工程依赖外，需要 Qt 5 或 Qt 6 Widgets 开发包。配置文件所在目录应包含 `model/mlp.onnx` 和 `model/label.txt`；配置需提供 `Camera.exposure_armor`。

```bash
cmake -S . -B build -DBUILD_KEYBOARD_REVIEW=ON
cmake --build build --target review -j4
```

以下命令会打开实际相机和串口，仅供完成接口确认后的人工操作；本次没有执行：

```bash
./build/review ./text.yaml /dev/ttyACM0 0 5 1 1
```

参数依次为：配置文件、串口、敌方颜色（0 蓝/1 红）、角速度（度/秒）、yaw 方向（1/-1）、pitch 方向（1/-1）。速度有效范围为大于 0 且不超过 20 度/秒。

- 先点击相机窗口；上下左右控制转动，空格按住请求发射，释放停止请求。
- B/R 切换识别颜色，Q/Esc 退出。
- 像素坐标以原图左上角为原点，x 向右、y 向下；窗口缩放不改变标注的原图坐标。
- 不构建该测试入口时，可配置 `-DBUILD_KEYBOARD_REVIEW=OFF`，避免为其他目标引入 Qt 依赖。
